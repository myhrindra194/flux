# Fullstack Flutter App

A Flutter full-stack application built to demonstrate:

- JWT authentication
- REST API integration
- Clean / Feature-First architecture
- Repository Pattern
- Local data persistence
- Offline mode
- Network error handling
- Unit testing

## Tech Stack

- Flutter
- Dart
- Riverpod
- GoRouter
- Dio
- Supabase
- Hive
- Mocktail

## Architecture

The project follows a Feature-First architecture with a clear separation between:

- Data
- Domain
- Presentation
